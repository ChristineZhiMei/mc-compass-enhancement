# 指南针搜索体验与范围增强

## 需求

1. 将最大探测范围从 128 格提升到 256 格。
2. 配置界面新增独立的物品历史行，展示之前选择并实际触发过搜索的物品，支持快速重新选择。
3. 搜索成功提示增加“上 / 中 / 下”，帮助玩家判断目标的垂直方向。
4. 调研如何改变搜索方式，以支持更大范围并提高搜索效率。

## 实现约定

- 历史是客户端本地持久化的最近 8 个目标物品 Identifier，按最近搜索优先去重保存。
- 只有已配置指南针实际发送扫描请求时才记入历史；只选择或保存但未搜索不计入。
- 历史行点击物品后直接回填目标，仍需玩家保存配置。
- 目标与玩家 Y 坐标差大于 2 格显示“上”，小于 -2 格显示“下”，其余显示“中”。
- 本轮实现范围、历史与方向反馈；搜索方式调研输出独立结论，不在未验证前重写世界扫描架构。

## 后续优化需求

- 实施已调研的短期方案：已加载区块近到远复用，容器与方块扫描共享当前最佳距离上界。
- 区块、Section 或容器位置的最小可能距离已不能优于当前结果时直接剪枝。
- 保持精确最近结果、loaded-only、同步服务端读取与不读玩家 Inventory 约束；不引入跨 tick 任务或增量索引。
