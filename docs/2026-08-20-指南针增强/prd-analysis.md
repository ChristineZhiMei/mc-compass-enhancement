# 需求分析：指南针增强 Mod

## 目标

在不新增物品的前提下增强原版指南针，使每一只指南针都能保存独立探测配置，并由服务端在当前维度执行一次最近目标搜索。

## 核心约束

- 玩家物品栏及装备永远不是搜索源。
- 非 BlockItem 不能启用实体方块搜索。
- 客户端不提供可信扫描参数，服务端必须从主手指南针读取配置。
- 扫描不能加载新区块，不能跨维度，不能持续自动运行。
- V1 不支持矿车、船等移动容器实体。

## 验收重点

- 三个合法来源能独立启用并统一选择最近目标。
- 成功与失败都通过 ActionBar 反馈；失败清除旧定位。
- 每只指南针配置互不影响，重启后仍由 ItemStack 数据组件持久化。
- Java 21 下 Gradle 编译和 Fabric remap 打包成功。
